# Ongwu Simple 主题介绍

Ongwu Simple 是一个专为 Hexo 博客设计的简洁主题，注重用户体验和视觉效果。

## 设计理念

本主题遵循"简洁是智慧的灵魂"的设计理念，通过简洁的布局和优雅的样式，为用户提供最佳的阅读体验。

## 主要功能

### 1. 两列布局
- **左侧边栏**: 包含个人头像、网站名称、导航菜单、搜索功能、个人名言和最近更新
- **右侧主区**: 显示文章列表、分类、标签、归档等内容

### 2. 文章展示
- 文章标题突出显示
- 100字内容预览
- 发布时间和分类信息
- 支持分页显示

### 3. 搜索功能
- 实时搜索文章内容
- 支持标题和内容搜索
- 搜索结果高亮显示

### 4. 分类标签系统
- 完整的分类管理
- 标签云展示
- 按分类和标签筛选文章

### 5. 归档功能
- 按年份归档文章
- 清晰的年份分组
- 快速定位历史文章

## 技术特点

- 使用现代 CSS 技术
- 完全响应式设计
- 优化的加载性能
- 良好的 SEO 支持

## 自定义配置

主题支持丰富的自定义选项，包括：

- 个人头像设置
- 社交链接配置
- 颜色主题调整
- 布局参数修改

通过简单的配置，您就可以拥有一个个性化的博客主题。
